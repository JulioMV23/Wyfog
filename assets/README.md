# Recursos Visuales y Capturas de Pantalla de Wyfog

Este directorio almacena los recursos gráficos y capturas de pantalla oficiales destinados a la presentación pública de **Wyfog** en GitHub.

## Contenido

- `wyfog-logo.png`: Logotipo oficial de Wyfog en alta resolución (fondo transparente).
- `../screenshots/`: Directorio raíz que almacena las 25 capturas de pantalla oficiales (`.webp`) de la interfaz de la aplicación en Android y Windows (en Modo Claro y Modo Oscuro), integradas en el `README.md` principal.

## Guía para la incorporación de capturas de pantalla

Para preservar la privacidad y la seguridad de los usuarios y desarrolladores, las capturas que se añadan a este directorio deben cumplir estrictamente las siguientes pautas:

1. **Datos Ficticios:** Utilizar exclusivamente datos de ejemplo creados para demostración, viajes a destinos genéricos o rutas turísticas públicas.
2. **Sin Documentos Sensibles:** **Bajo ninguna circunstancia** se deben incluir imágenes con números de pasaporte reales, documentos nacionales de identidad (DNI/NIE), números de tarjeta de crédito, billetes de avión reales con localizadores PNR o códigos QR personales.
3. **Sin Ubicaciones Personales:** No mostrar domicilios particulares, lugares de trabajo ni ubicaciones privadas en los mapas o recuerdos geolocalizados.
4. **Formato y Optimización:** Emplear imágenes en formato PNG o WebP, optimizadas para la web y con nombres descriptivos (por ejemplo: `01_pantalla_viajes.png`, `02_itinerario_modo_en_vivo.png`, `03_mapa_offline_rutas.png`, `04_boveda_documental.png`, `05_control_gastos_divisas.png`).
